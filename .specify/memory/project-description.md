# MathMate 项目描述

MathMate 是面向高一年级学生的数学学习辅助应用，通过启发式教学培养独立思考能力。

## 核心理念

**授人以渔而非授人以鱼**：苏格拉底式引导、多轮对话，让学生自主得出结论而非直接给出答案。

## 核心价值

1. **独立思考**：通过对话引导培养自主学习能力
2. **个性化辅导**：基于知识盲区图谱，仅推送薄弱点内容
3. **情绪支持**：感知挫败情绪，适时停止并给予安抚
4. **长期记忆**：全生命周期记忆 + 艾宾浩斯间隔复习
5. **低门槛输入**：多模态支持（文本/语音/图像），优先轻量化题型

## 目标用户

- **主要用户**：高一年级学生，需要个性化数学辅导和启发式引导
- **次要用户**：家长，通过兑换券机制参与激励环节

**用户特征**：对传统严肃教学有抵触心理，需要低门槛提问、情绪支持和个性化学习路径

## 核心功能
    
### 教学核心
- **启发式引导**：苏格拉底式多轮对话，引导学生自主得出结论
- **个性化诊断**：动态知识盲区图谱，精准推送薄弱点内容
- **情绪感知**：监测交互情绪，适时停止追问并给予安抚
- **记忆强化**：全生命周期记忆 + 艾宾浩斯间隔复习

### 内容管理
- 高一年级数学大纲对标题库
- 轻量化题型优先（选择题/判断题）
- 三级难度阶梯题库
- 用户纠错反馈机制

### 多模态交互
- 文本输入 + 数学符号识别
- 语音交互（口语化数学表达）
- 图像OCR（拍照识别题目）
- LaTeX公式专业渲染

### 激励机制
- 多维积分系统（提问/答对/完成作业）
- 可视化成就中心（积分/等级/进度条）
- 实物兑换券系统

### 情感设计
- 口语化亲切语言，避免机器化表达
- 适时鼓励、安慰和人生哲理
- 活泼明亮界面设计

## 项目约束

### 教学约束
- **禁止直接给答案**：必须通过引导培养独立思考
- **情绪优先**：检测挫败感时立即停止并给予支持
- **个性化推送**：仅推送薄弱点内容，避免无效学习

### 内容约束
- 严格对标高一年级数学教学大纲
- 与学校进度同步，不增加额外负担
- 通过用户纠错机制保证内容准确性

### 技术约束
- 支持多模态输入（文本/语音/图像）
- 支持LaTeX公式渲染和OCR识别
- 具备长期记忆和知识状态追踪
- 响应式Web应用，适配移动端浏览
