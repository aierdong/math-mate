# Math Mate 项目描述

## 项目概述

Math Mate 是一个面向高一年级学生的数学学习辅助应用，采用启发式教学理念，通过苏格拉底式引导、个性化辅导和情感支持，帮助学生培养独立思考能力，建立学习信心。应用强调"授人以渔"而非"授人以鱼"，将单向答疑转变为双向探讨，让学习过程充满温度。

## 项目目标

### 核心价值主张

1. **培养独立思考能力**：通过多轮对话引导，让学生自己得出结论，而非直接给出答案
2. **精准个性化辅导**：基于知识盲区图谱，靶向推送薄弱点内容，避免无效学习
3. **建立学习信心**：通过情绪感知和托底机制，保护学习兴趣，避免挫败感
4. **强化长期记忆**：利用全生命周期记忆和艾宾浩斯回顾，对抗遗忘曲线
5. **降低学习门槛**：支持多模态输入（文本、语音、图像），优先使用轻量化题型（选择题、判断题）

### 教学原则

- **授人以渔**：培养独立思考能力，而非依赖性
- **主动思考**：将单向答疑转变为双向探讨
- **保护信心**：维护学习兴趣是第一位的
- **精准诊断**：识别表象错误背后的根本原因
- **减负增效**：只学不会的，不浪费时间在已掌握的内容上

## 目标用户

### 主要用户
- **高一年级学生**：正在学习高中数学，需要个性化辅导和启发式引导

### 次要用户
- **家长**：参与激励环节，通过兑换券机制与孩子互动

### 用户特征
- 需要数学学习辅助，但可能对传统严肃教学方式有抵触
- 需要降低提问的心理和物理门槛
- 需要建立学习信心，避免挫败感
- 需要个性化的学习路径，而非一刀切的内容推送

## 核心功能领域

### 1. 核心教学功能 (Core Pedagogy)

#### 启发式教学
- **苏格拉底式引导** (F-P1)：通过多轮对话拆解问题，引导孩子自己得出结论
- **双向提问机制** (F-P2)：确认理解后立即反向抛出相关问题，巩固知识迁移
- **情绪感知与托底** (F-P3)：监测交互轮次和情绪，适时停止追问并给予安抚

#### 个性化辅导
- **动态知识盲区图谱** (F-P4)：构建知识状态树，标记薄弱节点而非仅记录错题
- **靶向辅导推送** (F-P5)：仅推送薄弱点相关内容，避免无效学习

#### 长期记忆
- **全生命周期记忆** (F-P6)：记住每个问题，在对话中自然引用历史
- **艾宾浩斯回顾** (F-P7)：间隔性复习旧知识点，对抗遗忘

### 2. 内容与知识库管理 (Content Management)

- **大纲对标知识库** (F-C1)：内置完整高一年级数学教学大纲，支持标签管理
- **轻量化题型优先** (F-C2)：优先使用选择题和判断题，降低输入门槛
- **阶梯式题库** (F-C3)：同一知识点包含3个难度等级，默认从基础开始
- **纠错与更新接口** (F-C4)：允许用户对题目或解析报错

### 3. 交互与输入/输出 (Interaction & I/O)

- **多模态输入**：
  - 全能键盘支持 (F-I1)：支持文本输入和数学符号自动识别
  - 语音交互 (F-I2)：识别口语化数学表达
  - 图像识别 OCR (F-I3)：拍照识别手写或印刷体题目
- **专业级公式渲染** (F-I4)：使用 LaTeX 完美渲染数学内容

### 4. 激励与奖励机制 (Motivation & Gamification)

- **多维积分系统** (F-M1)：提问、答对、完成作业均可获得积分
- **可视化成就中心** (F-M2)：展示积分、等级勋章、进度条
- **实物兑换凭证** (F-M3)：生成兑换券，连接虚拟学习与现实奖励

### 5. 应用角色与情感支持 (Persona & Tone)

- **有温度的导师** (N-P1)：使用口语化、亲切、幽默的语言，避免机器语言
- **情绪价值输出** (N-P2)：适时穿插鼓励、安慰和人生哲理
- **活泼明亮的界面** (N-P3)：避免沉闷深色或严肃学术蓝

## 项目约束与假设

### 内容约束
- **严格不超纲**：内容必须与高一年级数学教学大纲完全对标
- **与学校同步**：确保与学校教学进度同步，不增加额外负担
- **内容准确性**：通过纠错机制保证内容的持续准确性

### 教学约束
- **禁止直接给答案**：必须通过引导让学生自己得出结论
- **保护学习兴趣**：当检测到挫败感时，必须停止追问并给予支持
- **降低输入门槛**：优先使用选择题和判断题，减少公式输入负担

### 用户体验约束
- **情绪感知优先**：系统需监测交互轮次和情绪关键词
- **个性化推送**：严禁一股脑罗列整章知识点，仅推送薄弱点内容
- **情感连接**：像真人老师一样熟悉学生，建立情感连接

### 技术假设
- 支持多模态输入（文本、语音、图像）
- 支持 LaTeX 公式渲染
- 支持 OCR 图像识别
- 支持语音识别和口语化数学表达识别
- 具备长期记忆和知识状态追踪能力

## 技术背景

### 核心技术需求
- **多模态输入处理**：文本、语音、图像识别
- **数学公式渲染**：LaTeX 或同等技术
- **知识图谱构建**：动态知识状态树
- **对话系统**：多轮对话、情绪感知
- **记忆系统**：全生命周期记忆、间隔复习算法

### 平台要求
- 能适应移动端浏览的 Web 应用
- 支持拍照和语音输入，或者通过上传图片或语言文件输入
- 流畅的公式渲染性能
